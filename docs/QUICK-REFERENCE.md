# Melisma quick reference

*One page. The full guide is the [Pilot's Notes](PILOTS-NOTES.md).*

## Start

**PLAY** starts and stops the band. **HOME + PLAY** is the built-in lesson. **PRESETS** steps through 64 pieces.
**HOME + ARP** makes a whole new one.

## The dials

| | Alone | EDIT held | HOME held | GLO held |
|---|---|---|---|---|
| **KNOB1** | Mood | Colour (scale) | Bass level | Bass instrument |
| **KNOB2** | Energy | Boost (to 11) | Chords level | Chords instrument |
| **KNOB3** | Style | Feel (metre) | Melody level | Melody instrument |
| **KNOB4** | Shape | Length | Pulse level | Room |
| **SELECT** | Key | Key layout | | |
| **ALGORITHM** | Variation | Tempo | | |
| **PRESETS** | Shipped pieces | Overall level | | |

## The four parts: FX bass, SCL chords, ENV melody, LFO pulse

| | |
|---|---|
| Tap | Out at the next bar, or back in |
| Hold half a second | Take the seat: you play it |
| EDIT + button | That part alone, while held |
| HOME + button | Freeze the part as it is |
| SEQ + button | Its next way of playing |
| GLO + button | Its next instrument |

Lights: lit = the band, blinking = you, glowing = frozen, dark = out.

## Playing

| | |
|---|---|
| Keys | Notes that always fit. Lit keys are home |
| EDIT + SELECT | Layout: EASY (five safe notes), SCALE, SNAP, PIANO |
| EDIT + PLAY | Time lock: your playing waits for the beat |
| OCT−, OCT+ | Your octave |
| ARP | A fill; held, a build |
| REC | Record a looping phrase; again to stop |
| HOME + REC | Undo the last pass; held, clear |
| EDIT + REC | Snap recordings to the beat, or not |

## The panel: hold SEQ (or tap it to stay)

| Keys | |
|---|---|
| Black 1 to 5 | INTRO, A, B, BREAK, ENDING |
| Black 6 to 9 | A new way of playing: bass, chords, melody, pulse |
| Black 10, 11 | BACK (undo), ROLL (new variation) |
| White 1 to 8 | Scenes. HOME + key keeps the piece there |
| White 9 to 16 | Chords: BLOCK, OPEN, CLIMB, FALL, WAVE, BROKEN, ROLLED, OFFBEAT |

## Keeping and sharing

| | |
|---|---|
| SAVE (tap) | Keep everything now. Its light glows when something is unsaved |
| SAVE (hold) | Show the piece's code, large |
| HOME + SAVE | Type a code in: keys are letters, SELECT any character, ALGORITHM moves, PLAY accepts |

## In trouble

Hold **OCT−** while switching on for the updater. See [INSTALL.md](INSTALL.md).
